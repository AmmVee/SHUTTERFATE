ПРОДОЛЖАЕМ РАЗРАБОТКУ SHUTTERFATE (Roguelite про фотокамеру)

ТЕКУЩИЙ СТЕК:
- Godot 4.2+, GDScript
- Изометрия 2.5D (y_sort_enabled, z_index по Y)
- Движение: WASD → iso-трансформация
- Бой: ПКМ (прицел) + ЛКМ (щелчок затвора)
- Формула урона: BASE × Композиция × Фокус × Экспозиция × ISO × Диафрагма × Плёнка × Реликвия

СЦЕНЫ:
- hub.tscn — стартовая "Тёмная комната" (кабинет фотографа)
- main.tscn — процедурная комната с врагами (забег)
- player.tscn — игрок с UI (HP, фокус, плёнка, параметры камеры)
- enemy_smear.tscn — враг "Смазь" (медленный, масштабируется по этажам)
- enemy_grain.tscn — враг "Зернистость" (быстрый, зигзаг, масштабируется)

СКРИПТЫ (Autoload):
- game_manager.gd — отпечатки, смерти, убийства, уровень камеры, реликвии
- film_manager.gd — 7 плёнок (Обскура, Хрома, Нуар, Инфракраска, Полароид, Кросс-процесс, Кадр Ноль)
- relic_manager.gd — 20 реликвий (экипировка, эффекты, счётчики)

СКРИПТЫ (игровые):
- hub.gd — хаб: спавн игрока, селектор плёнок, UI реликвий, подсказки [E]
- main.gd — спавнер врагов/босса, двери, переходы между комнатами, телепорт
- room_generator.gd — процедурная изометрическая комната 20×14 (было 16×12), стены с проёмами
- floor_generator.gd — генерация этажа (3-6 комнат), коридоры между дверями
- player.gd — движение, прицел, фото-бой, перезарядка, все эффекты реликвий
- enemy_smear.gd / enemy_grain.gd — AI, масштабирование по этажам, призрачные копии
- boss_portraitist.gd — Босс "Портретист": 3 фазы, силуэты, вспышки, бешенство
- wall.gd — прозрачность при прохождении позади
- vintage_film.gdshader — постпроцесс (grain, aberration, vignette)

УПРАВЛЕНИЕ:
- WASD — движение (изометрия)
- ПКМ (hold) — прицел, накопление фокуса
- ЛКМ — щелчок затвора (урон)
- 1/2/3 — выдержка (1/500, 1/125, 1/30)
- 4 — ISO (100 ↔ 3200)
- 5 — диафрагма (f/1.4 ↔ f/16)
- E / Enter — взаимодействие в хабе

АРХИТЕКТУРА ПРОЕКТА (для понимания):

Hub.tscn
  └── Player (instance)
  └── CameraDesk (Area2D) → [E] → GameManager.start_run()
  └── NPC (Area2D) → [E] → dialog + магазин реликвий
  └── CanvasLayer → UI (PromptLabel, StatsLabel, FilmSelector, RelicUI)

Main.tscn
  └── Player (instance)
  └── FloorGenerator (Node2D) → room_generator.gd instances
  └── PostProcess (CanvasLayer) → vintage shader
  └── Enemies (spawned dynamically via main.gd)
  └── Doors/Exit (spawned dynamically)

GameManager (Autoload)
  └── prints, total_deaths, total_kills, camera_level
  └── owned_relics, equipped_relics
  └── start_run() → sync relics → change_scene to Main
  └── end_run(success) → add prints → sync back → change_scene to Hub

FilmManager (Autoload)
  └── 7 films, current_film
  └── calculate_damage_for_enemy() → film-specific effects

RelicManager (Autoload)
  └── 20 relics, owned/equipped (max 3)
  └── effect checkers, runtime counters (reload_counter, shot_counter, etc.)
  └── reset_run() on new run start
